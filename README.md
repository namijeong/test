# SKCT 수열 · 창의수리 모의고사 — 3단계 (UI 디자인)

PRD.md 9장 '1단계 → 2단계 → 3단계' 결과물입니다. PRD 4장 기능 요구사항(F1~F6)과 6장 화면 구성을 반영했습니다.

## 3단계 UI
- 시험: 화면에 고정된 타이머 배지(2분 미만 빨간색, 모바일에서는 오른쪽 아래), 진행 바, 문항 카드, 수열 강조 박스
- 쉬는 시간: 큰 카운트다운 + 진행 바
- 결과: 목표 대비 %p 지표(미달 빨간 ↓), 정답 보기 초록 · 내가 고른 오답 빨간 취소선
- 홈: 안내 문구, 회차 카드 2줄 × 5칸, 🟢/🟠 상태
- 라이트·다크 모드 모두 지원(`.streamlit/config.toml`의 `[theme.light]`, `[theme.dark]`), 390px 모바일 폭에서 가로 스크롤 없음

## 기능
- 문제 유형: 수열 15개, 창의수리 13개 (난이도 하/중/상별 구성), 1,200문항 모두 서로 다름
- 문항별 풀이 + 💡 암산 팁, 흔한 실수 값을 함정 보기로 사용
- 과목별 15분 타이머(1초 갱신, 응답 수·목표 페이스 표시), 시간 종료 시 자동 제출
- 쉬는 시간 1분 타이머, 끝나면 다음 과목 자동 시작 (바로 시작 버튼 포함)
- 회차 종료 후 일괄 채점: 정답률(맞힘 ÷ 푼 수)·풀이율(푼 수 ÷ 전체), 목표 80% 대비 표시
- 오답 노트 · 오답 재시험(20문항·15분, 부족하면 유사 문제로 채움, 맞히면 노트에서 제거)
- 홈 회차 카드 기록 표시, 학습 기록 표·그래프
- 사이드바 기록 백업/복원(JSON), 시험 중단

## 실행 · 검증
```bash
pip install -r requirements.txt
streamlit run app.py
python check.py      # 문제 생성기 검증 (1,200문항 중복·정답 + 17,400문항 스트레스 테스트)
python test_app.py   # 앱 흐름 테스트 (자동 제출, 쉬는 시간, 채점 수치, 오답 재시험 등 17개 항목)
```
